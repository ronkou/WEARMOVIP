# WEARMOVIP

WEARMO VIP 等級會員專屬平台 — 尊享福利、限定活動、優先預購。

## 技術棧

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **部署**: Vercel

## 本地開發

```bash
npm install
npm run dev
```

## 環境變數

```env
NEXT_PUBLIC_API_BASE=https://acc.wearmo.app
```

## 概述

WEARMOVIP 是 WEARMO 會員系統的 VIP 等級專屬前端，展示：
- VIP 專屬福利與權益說明
- 即將舉行的 VIP 限定活動
- 等級門檻與升級說明
- 連結至 [WEARMO Account](https://acc.wearmo.app) 會員中心
